# 万能创作终端 · TideVerse 版快速上手（1 页）

> TideVerse 版默认连接 [TideVerse](https://tideverse.cn)：用 TideVerse 账号登录，或在 TideVerse 控制台创建令牌后填进软件即可。下面的步骤对其他 OpenAI 兼容站点同样适用。

> 适合：使用任意 new-api / OpenAI 兼容站点的用户。详细说明见 [使用手册](使用手册.md)。软件里的设置入口叫「配置」。

## 第 1 步：下载安装

1. 打开 GitHub 发布页 <https://github.com/ginsonko/tideverse/releases>（或官网下载区）。
2. 选文件：
   - Windows：`…-Setup.exe`（安装版，推荐）或 `…-Portable.exe`（免安装版）
   - Mac Apple 芯片（M1–M4）：`…-mac-arm64.dmg`；Mac Intel：`…-mac-x64.dmg`（需要 macOS 13 或更高）
3. 安装：
   - Windows：双击安装。被拦住时点「更多信息」→「仍要运行」。
   - Mac：把「万能创作终端 TideVerse」拖进「应用程序」。第一次打开：macOS 13/14 **右键 →「打开」→「打开」**；macOS 15 先双击一次点「完成」，再到 **系统设置 → 隐私与安全性** 点「仍要打开」。提示“已损坏”就在「终端」运行：
     ```
     sudo xattr -dr com.apple.quarantine "/Applications/万能创作终端 TideVerse.app"
     ```

## 第 2 步：在 API 站点准备 Key

1. 在站点注册、充值。
2. 进入「令牌 / API Key」页，点「添加令牌」，建一个 Key（建议设额度上限）。站点把文本、生图、视频分在不同分组时，再按用途多建几个。
3. 复制 Key（`sk-` 开头），记下接口地址：`https://你的站点域名/v1`。

## 第 3 步：在软件里连接

1. 打开软件 → **配置 → 连接 → 手动添加**。
2. 填 **名称**、**接口地址**、**API Key**（填一次，文本 / 生图 / 视频共用）。
3. 选 **文本**、**生图**、**视频** 三项默认模型（点模型框会列出这个 Key 能用的模型）。某一项要用别的 Key 或地址，点它右边的 **「单独设置」**。
4. 点 **保存** → **检查连接**，看到“连接正常”就好了。

## 第 4 步：开始创作

回到首页，在输入框里说（可以直接复制）：

- 写文案：`给新品焦糖拿铁写 3 条小红书文案，每条不超过 80 字`
- 生成图片：`帮我做一张新品咖啡海报，暖色调，留出标题位置`
- 生成视频：`把这张图做成 5 秒视频，镜头缓慢推近`
- 做项目：`做一个三格小漫剧：主角是一只想当程序员的橘猫，先给我分镜`

成果自动保存在右侧「作品」里。

## 记住这几个键

`F1` 帮助 · `F2` 换界面（新手推荐「口袋」） · `Ctrl+K` 搜索一切 · `Ctrl+N` 新对话（Mac 用 `⌘`）

## 其他

- 花费上限：**配置 → 账本与上限**（单个对话 / 每天 / 每月）。
- 更新：启动 1 分钟后和每 6 小时检查一次，有新版左下角提示「立即更新 / 稍后 / 跳过此版本」，**从不强制**；**配置 → 关于** 可手动「检查更新」。更新保留全部设置和对话。
- 卸载：Windows「设置 → 应用」或软件 **配置 → 关于 →「卸载本软件」**（会先关掉后台进程，并询问是否删除数据，默认保留）；免安装版先点「清除软件数据」再删 exe；Mac 把「万能创作终端 TideVerse」拖进废纸篓。
